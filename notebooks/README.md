# Notebooks

## Math Helpers

Open `math_helpers.ipynb` in VS Code, Jupyter, or another notebook viewer.

Use the project environment as the kernel:

```bash
uv run python --version
```

If your editor asks for a Python interpreter, choose:

```text
.venv/bin/python
```

The notebook contains helpers for derivatives, Jacobians, linearization, Euler discretization, integration, expectations, Bellman calculations, and one-step LQR gains.
